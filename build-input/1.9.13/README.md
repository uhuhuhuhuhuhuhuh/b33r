# B33R IPTV 1.9.13

This version replaces the beer-dashboard presentation with an original media-hub interface derived from the interaction patterns observed in the supplied Plex Android bundle.

## Interface changes

- Near-black and charcoal surfaces with a restrained B33R amber accent.
- Flat, compact application header instead of a raised beer-themed hub card.
- Compact section navigation instead of oversized launch tiles.
- Poster-first library cards with titles and metadata below the artwork.
- White remote-focus frames and amber selected states.
- Neutral category chips and a low-profile search field.
- Cleaner sign-in screen and responsive phone, tablet, portrait, landscape, Android TV, and Fire TV layouts.

Plex names, logos, fonts, artwork, code, and branded assets are not included. Existing B33R login, updater, favorites, continue-watching, VLC, Media3, fallback, quality, audio, and subtitle behavior remains intact.
