# B33R IPTV 1.9.13 preview

This APK contains the original B33R media-hub redesign derived from the interaction patterns observed in the supplied Plex Android bundle.

It uses near-black surfaces, compact navigation, poster-first cards, neutral metadata, amber selected states, and white remote-focus frames. Plex branding, logos, fonts, artwork, and code are not included.

Existing updater, favorites, continue-watching, VLC, Media3, fallback, quality, audio, and subtitle behavior is preserved.

It is signed with GitHub Actions' debug key because production signing secrets were not available. It cannot update a production-signed installation in place.
