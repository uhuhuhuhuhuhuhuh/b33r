# B33R IPTV 1.9.11 preview

This APK contains the new beer-themed Smarters-style interface and the existing VLC/Media3 playback stack.

It is signed with GitHub Actions' debug key because the production signing secrets were not available to the workflow. It cannot update an installed production-signed build in place; uninstall the current app before testing this preview.
