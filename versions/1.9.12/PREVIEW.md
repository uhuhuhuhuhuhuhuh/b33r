# B33R IPTV 1.9.12 preview

This APK contains the responsive beer-themed Smarters-style interface and the existing VLC/Media3 playback stack.

The interface reflows for portrait and landscape screens, adapts launch-card sizing, and constrains dynamic text to prevent overlapping and clipping.

The updater now includes a visible manual check button and reports up-to-date, preview-channel, and network/error results instead of failing silently.

It is signed with GitHub Actions' debug key because production signing secrets were not available. It cannot update a production-signed installation in place, and another independently debug-signed preview cannot update it in place.
